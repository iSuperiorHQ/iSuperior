# **Problem 105: 3Sum**

**Company:** ServiceNow

**Category:** Arrays / Two Pointers / Sorting

**Difficulty:** Medium

---

# **Problem Description**

A financial risk analysis platform processes large streams of transaction adjustments represented as positive and negative integers.

Analysts want to identify all unique combinations of three transactions whose total impact becomes exactly:

```text id="m2v8zk"
0
```

Such combinations help detect:

* balance-neutral transaction groups
* anomaly correction patterns
* offsetting financial operations

Your task is to find all unique triplets in the array whose sum equals zero.

Interviewers typically expect the optimized:

```text id="x7m1qa"
sorting + two-pointer approach
```

rather than brute-force enumeration.

---

# **Task**

Given an integer array:

```text id="u3m8qp"
nums
```

return all unique triplets:

```text id="f9m1zk"
[a, b, c]
```

such that:

```text id="r2m8vx"
a + b + c = 0
```

---

# **Important Rules**

* Each triplet must contain elements from different indices
* Solution set must NOT contain duplicate triplets
* Triplets may appear in any order

---

# **Input Format**

First line contains integer:

```text id="n7m2qa"
N
```

representing size of array.

Second line contains:

```text id="p4m9xp"
N space-separated integers
```

representing array elements.

---

# **Output Format**

Print all unique triplets satisfying:

```text id="v1m8zk"
sum = 0
```

Each triplet should be printed in sorted order.

Triplets themselves may be printed in any order.

If no valid triplets exist, print:

```text id="g8m2vx"
No Triplets Found
```

---

# **Constraints**

* **3 ≤ N ≤ 5000**
* **-10⁵ ≤ nums[i] ≤ 10⁵**

# **Brute Force Approach**

Generate all possible triplets using:

* three nested loops

Check whether:

```text id="k2m1qa"
nums[i] + nums[j] + nums[k] == 0
```

---

## **Complexity of Brute Force Solution**

### Time Complexity

* **O(N³)**

Too slow for large inputs.

---

# **Optimized Sorting + Two Pointer Approach**

Sort the array first.

Then fix one element and solve remaining:

```text id="r7m2zk"
2Sum
```

problem using two pointers.

---

# **Efficient Strategy**

## Step 1 — Sort Array

Example:

```text id="u1m8xp"
[-1, 0, 1, 2, -1, -4]
```

becomes:

```text id="m4k8qa"
[-4, -1, -1, 0, 1, 2]
```

---

## Step 2 — Fix First Element

For every index:

```text id="v8m2zk"
i
```

use:

* `left = i + 1`
* `right = N - 1`

---

## Step 3 — Two Pointer Search

Compute:

```text id="x1m9vx"
sum = nums[i] + nums[left] + nums[right]
```

---

### If Sum < 0

Move:

```text id="z7m2qp"
left++
```

to increase sum.

---

### If Sum > 0

Move:

```text id="u4m8zk"
right--
```

to decrease sum.

---

### If Sum == 0

Store triplet.

Then skip duplicate values for:

* fixed element
* left pointer
* right pointer

---

# **Why Sorting Helps**

Sorting enables:

* duplicate elimination
* efficient two-pointer traversal
* monotonic movement decisions

---

# **Duplicate Handling Rules**

To avoid duplicate triplets:

---

## Skip Duplicate Fixed Elements

If:

```text id="k2m1qa"
nums[i] == nums[i-1]
```

skip current iteration.

---

## Skip Duplicate Left Values

After finding valid triplet:

```text id="r7m2zk"
while left < right AND nums[left] == nums[left - 1]
```

move:

```text id="u1m8xp"
left++
```

---

## Skip Duplicate Right Values

Similarly:

```text id="m4k8qa"
while left < right AND nums[right] == nums[right + 1]
```

move:

```text id="v8m2zk"
right--
```

## Sorting + Two Pointer Solution

### Time Complexity

* **O(N²)**

Where:

* sorting → `O(N log N)`
* two-pointer traversal → `O(N²)`

Overall dominant complexity:

```text id="x1m9vx"
O(N²)
```

### Space Complexity

* **O(1)** auxiliary space excluding output storage and sorting overhead.
