# **Problem 1091: In-Place String Compression**

**Company:** Adobe

**Topic:** Two Pointers (Read/Write)

**Difficulty:** Medium

---

## **Problem Description**

A large-scale logging system stores repeated character streams generated by real-time monitoring services.

To reduce storage consumption, the system compresses consecutive repeating characters directly inside the original character array without allocating additional memory.

Compression follows these rules:

* Consecutive repeating characters are replaced by:

  * the character itself
  * followed by its frequency count (only if frequency > 1)

For example:

```text id="m2v8zk"
aaabbcccc
```

becomes:

```text id="x7m1qa"
a3b2c4
```

The compression must be performed:

```text id="u3m8qp"
In-Place
```

using only constant auxiliary space.

Your task is to modify the character array directly and return the length of the compressed array.

---

## **Task**

Given a character array, compress it in-place and return the final compressed length.

---

## **Compression Rules**

### Rule 1

Only consecutive repeated characters are compressed together.

Non-adjacent occurrences are treated independently.

Example:

```text id="f9m1zk"
ababaa
```

remains:

```text id="r2m8vx"
abab a2
```

because only the final consecutive `aa` block is compressed.

---

### Rule 2

If a character appears once:

```text id="n7m2qa"
a
```

remains:

```text id="p4m9xp"
a
```

---

### Rule 3

If a character repeats multiple times:

```text id="v1m8zk"
aaaa
```

becomes:

```text id="g8m2vx"
a4
```

---

### Rule 4

Multi-digit frequencies must be stored as separate characters.

Example:

```text id="x2m1qa"
aaaaaaaaaaaa
```

becomes:

```text id="m9v2zk"
a12
```

stored as:

```text id="k4m8qp"
a 1 2
```

---

## **Important Constraint**

You must solve the problem using:

```text id="u7m1xp"
O(1) auxiliary space
```

Only the input array may be modified.

---

## **Input Format**

* First line: integer **N** — size of character array
* Second line: `N` space-separated lowercase characters

---

## **Constraints**

* **1 ≤ N ≤ 10⁵**
* Characters are lowercase English letters

---

## **Output Format**

* First line: integer representing compressed length
* Second line: compressed character array elements separated by spaces

---

```text id="v8m2zk"

```

---

## **Two Pointer Strategy**

Maintain:

```text id="x1m9vx"
readPointer
writePointer
```

### Read Pointer

Scans consecutive character groups.

### Write Pointer

Writes compressed output directly into the same array.

---

## **Efficient Compression Logic**

For every consecutive block:

1. Count frequency
2. Write character
3. If frequency > 1:

   * Convert count to string
   * Write each digit separately

No additional array is allowed.

---

## **Expected Complexity**

### In-Place Two Pointer Compression

* **Time Complexity:** `O(N)`
* **Space Complexity:** `O(1)`

Where:

* `N` = size of input array
